# 农信题库答案查询

在浏览器里把已保存的考试页面和「小包搜题」题库对齐，按页面顺序列出每题的序号和答案。

## 打开

用浏览器直接打开本目录的 `index.html`。

如果浏览器拦截了本地脚本，在本目录启动静态服务后再访问：

```bash
python3 -m http.server 8000
```

然后打开 <http://127.0.0.1:8000/>。

## 用法

1. 选择考试页面 HTML（浏览器另存的考试页）。
2. 选择小包搜题导出的 Excel。表头必须是：考题、答案、选项A、选项B、选项C、选项D。
3. 点击「开始查询」。

结果表只有两列：序号、答案。序号沿用页面上的题号，顺序与页面一致。对不上的题目答案留空，表格上方显示未匹配题数。
